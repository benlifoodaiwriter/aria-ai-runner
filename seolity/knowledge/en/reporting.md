# SEO reporting and daily briefings

## What a useful report contains
- Outcome KPIs: organic clicks, impressions, CTR, average position (impression-weighted), conversions/revenue from organic when available.
- Changes vs. previous period and the same period last year (seasonality).
- Winners and losers (pages and queries) with the likely reason.
- Actions taken (changes applied, experiments and their verdicts) and their measured effect.
- Top issues found (technical, content) and the prioritized next steps.

## Writing style for briefings
- Lead with the single most important insight, then 3–5 highlights. Use numbers with context ("clicks +18% week over week, mainly from 3 product pages").
- Separate facts from hypotheses; never invent data or causes. If data is missing (e.g., Search Console not connected), say so.
- Each insight should end with an action the user can take.

## Alerts
- Alert on significant drops (e.g., > 25% clicks for an important page vs. its normal level), sudden indexing loss, new 404s with traffic, sitemap/robots changes, Core Web Vitals regressions. Avoid alert fatigue by ignoring tiny absolute numbers.
