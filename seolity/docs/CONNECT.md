### هوش مصنوعی با کلید API

#### Anthropic Claude API

`هوش مصنوعی` `پولی (پیش‌پرداخت)` `۵ دقیقه`

بهترین کیفیت برای بازنویسی محتوا، متا و تحلیل سئو (مدل‌های Claude). هزینه بر اساس مصرف از اعتبار پیش‌پرداخت کم می‌شود.

**پیش‌نیازها:** ایمیل و شماره موبایل برای ساخت حساب؛ کارت بانکی بین‌المللی برای خرید اعتبار

1. وارد کنسول Anthropic شوید و حساب بسازید (یا با گوگل وارد شوید). [باز کردن کنسول](https://console.anthropic.com/)
2. از بخش Billing اعتبار (Credits) بخرید. بدون اعتبار، کلید کار نمی‌کند و خطای credit balance می‌گیرید. ۵ تا ۱۰ دلار برای شروع کافی است. [صفحه Billing](https://console.anthropic.com/settings/billing)
3. به صفحه API Keys بروید و «Create Key» را بزنید؛ یک نام مثل SEOlity بدهید. [ساخت کلید API (لینک مستقیم)](https://console.anthropic.com/settings/keys)
4. کلید را که با sk-ant- شروع می‌شود همان لحظه کپی کنید؛ دوباره نمایش داده نمی‌شود.

   ```
   sk-ant-api03-…
   ```
5. در SEOlity: تنظیمات ← هوش مصنوعی ← «Anthropic API key» را بچسبانید و Save بزنید. سپس «ارائه‌دهنده» را Anthropic بگذارید، تنظیمات را ذخیره و «تست اتصال» را بزنید.

**رفع مشکل**

- **خطای credit balance is too low** — اعتبار حساب تمام شده یا نخریده‌اید. از صفحه Billing اعتبار اضافه کنید.
- **خطای 401 / invalid x-api-key** — کلید ناقص کپی شده یا حذف شده. یک کلید جدید بسازید و دوباره ذخیره کنید.
- **خطای 429 (rate limit)** — حساب‌های تازه سقف درخواست کمی دارند. چند دقیقه صبر کنید؛ با افزایش خرید، سطح حساب (tier) بالا می‌رود.

**مستندات رسمی:** [مستندات شروع API](https://docs.claude.com/en/api/overview) · [کشورهای پشتیبانی‌شده](https://www.anthropic.com/supported-countries) · [قیمت‌ها](https://www.anthropic.com/pricing#api)

#### OpenAI API (GPT)

`هوش مصنوعی` `پولی (پیش‌پرداخت)` `۵ دقیقه`

مدل‌های GPT از طریق API. توجه: اشتراک ChatGPT Plus/Pro شامل اعتبار API نیست؛ برای استفاده از اشتراک، راهنمای «اشتراک ChatGPT» را ببینید.

**پیش‌نیازها:** حساب OpenAI و کارت برای خرید اعتبار

1. وارد پلتفرم OpenAI شوید یا ثبت‌نام کنید. [ورود به پلتفرم](https://platform.openai.com/)
2. در Billing یک روش پرداخت اضافه کنید و اعتبار بخرید (حداقل ۵ دلار). [صفحه Billing](https://platform.openai.com/settings/organization/billing/overview)
3. در صفحه API keys روی «Create new secret key» بزنید. Permissions را All بگذارید (یا حداقل Model capabilities: Write). [ساخت کلید API (لینک مستقیم)](https://platform.openai.com/api-keys)
4. کلید (sk-…) را فوراً کپی کنید.

   ```
   sk-proj-…
   ```
5. در SEOlity: تنظیمات ← هوش مصنوعی ← «OpenAI API key» ← Save؛ ارائه‌دهنده را OpenAI بگذارید و تست بزنید.

**رفع مشکل**

- **خطای insufficient_quota** — اعتبار ندارید یا تمام شده. اشتراک ChatGPT برای API حساب نمی‌شود.
- **model_not_found** — نام مدل را در تنظیمات بررسی کنید یا خالی بگذارید تا پیش‌فرض استفاده شود. برخی مدل‌ها نیاز به تأیید سازمان دارند.

**مستندات رسمی:** [شروع سریع](https://platform.openai.com/docs/quickstart) · [کشورهای پشتیبانی‌شده](https://platform.openai.com/docs/supported-countries) · [قیمت‌ها](https://openai.com/api/pricing/)

#### Google Gemini API

`هوش مصنوعی` `سطح رایگان دارد` `۳ دقیقه`

ساده‌ترین راه شروع: کلید رایگان با سقف استفاده روزانه از Google AI Studio.

**پیش‌نیازها:** یک حساب گوگل

1. Google AI Studio را باز کنید و با حساب گوگل وارد شوید (شرایط را بپذیرید). [باز کردن AI Studio](https://aistudio.google.com/)
2. روی «Get API key» و سپس «Create API key» بزنید. اگر پروژه نداشتید، گزینه ساخت پروژه جدید را انتخاب کنید. [صفحه کلیدها (لینک مستقیم)](https://aistudio.google.com/app/apikey)
3. کلید (AIza…) را کپی کنید.

   ```
   AIzaSy…
   ```
4. در SEOlity: تنظیمات ← هوش مصنوعی ← «Google Gemini API key» ← Save؛ ارائه‌دهنده را Gemini بگذارید و تست بزنید.

**رفع مشکل**

- **User location is not supported** — Gemini فقط در کشورهای مشخصی ارائه می‌شود و درخواست از محل سرور هاست شما ارسال می‌شود. فهرست مناطق را ببینید یا ارائه‌دهنده دیگری انتخاب کنید.
- **خطای 429 / RESOURCE_EXHAUSTED** — سقف رایگان پر شده. صبر کنید یا Billing را در پروژه فعال کنید.

**مستندات رسمی:** [راهنمای کلید API](https://ai.google.dev/gemini-api/docs/api-key) · [مناطق در دسترس](https://ai.google.dev/gemini-api/docs/available-regions) · [سقف‌ها و قیمت](https://ai.google.dev/gemini-api/docs/pricing)

#### OpenRouter

`هوش مصنوعی` `پیش‌پرداخت + مدل‌های رایگان` `۵ دقیقه`

یک کلید برای صدها مدل (Claude، GPT، Gemini، Llama، DeepSeek، Qwen…). مدل‌هایی که آخرشان :free است رایگان‌اند (با سقف).

**پیش‌نیازها:** حساب OpenRouter (گوگل/گیت‌هاب/ایمیل)

1. در OpenRouter ثبت‌نام کنید. [باز کردن OpenRouter](https://openrouter.ai/)
2. برای مدل‌های غیررایگان از صفحه Credits اعتبار بخرید. [صفحه Credits](https://openrouter.ai/settings/credits)
3. در صفحه Keys روی «Create Key» بزنید و کلید (sk-or-…) را کپی کنید. [ساخت کلید (لینک مستقیم)](https://openrouter.ai/settings/keys)

   ```
   sk-or-v1-…
   ```
4. شناسه مدل دلخواه را از فهرست مدل‌ها کپی کنید (مثلاً anthropic/claude-sonnet-4.5 یا یک مدل :free). [فهرست مدل‌ها](https://openrouter.ai/models)
5. در SEOlity: تنظیمات ← هوش مصنوعی ← «OpenRouter API key» ← Save؛ ارائه‌دهنده را OpenRouter و مدل را وارد کنید و تست بزنید.

**رفع مشکل**

- **خطای 402** — اعتبار کافی نیست؛ اعتبار بخرید یا یک مدل :free انتخاب کنید.
- **پاسخ JSON نامعتبر** — مدل‌های خیلی کوچک گاهی خروجی ساختاریافته را خراب می‌کنند. یک مدل قوی‌تر انتخاب کنید.

**مستندات رسمی:** [شروع سریع](https://openrouter.ai/docs/quickstart) · [مدل‌ها و قیمت‌ها](https://openrouter.ai/models)

#### Ollama (local / self-hosted)

`هوش مصنوعی` `رایگان، بدون حساب` `۱۵ دقیقه`

مدل‌های متن‌باز روی سرور خودتان؛ بدون کلید، بدون ارسال داده به بیرون. نیاز به سرور با رم کافی (حداقل ۸ تا ۱۶ گیگ برای مدل‌های ۷ تا ۸ میلیارد پارامتری).

**پیش‌نیازها:** یک سرور یا کامپیوتر که وردپرس به آن دسترسی شبکه‌ای دارد

1. Ollama را نصب کنید (ویندوز/مک/لینوکس). روی لینوکس: [دانلود Ollama](https://ollama.com/download)

   ```
   curl -fsSL https://ollama.com/install.sh | sh
   ```
2. یک مدل دریافت کنید. برای فارسی مدل‌های Qwen یا Gemma گزینه‌های خوبی هستند: [کتابخانه مدل‌ها](https://ollama.com/library)

   ```
   ollama pull qwen2.5:7b
   ```
3. اگر وردپرس روی سرور دیگری است، Ollama را روی همه رابط‌ها در دسترس کنید و پورت 11434 را فقط برای IP سرور وردپرس باز کنید:

   ```
   OLLAMA_HOST=0.0.0.0:11434 ollama serve
   ```
4. در SEOlity: تنظیمات ← هوش مصنوعی ← ارائه‌دهنده Ollama، آدرس (مثلاً http://127.0.0.1:11434) و نام مدل (qwen2.5:7b) را وارد کنید، ذخیره و تست کنید.

**رفع مشکل**

- **Connection refused / timeout** — وردپرس به آدرس Ollama دسترسی ندارد. روی هاست اشتراکی معمولاً امکان‌پذیر نیست؛ از VPS استفاده کنید یا آدرس عمومی امن بدهید.
- **کند بودن پاسخ** — مدل کوچک‌تر یا سرور با GPU انتخاب کنید و «مهلت زمانی هوش مصنوعی» را در تنظیمات بیشتر کنید.

**مستندات رسمی:** [پرسش‌های متداول Ollama](https://github.com/ollama/ollama/blob/main/docs/faq.md)

### هوش مصنوعی با اشتراک (Claude / ChatGPT) از طریق GitHub

#### GitHub token

`لازم برای اشتراک و ذخیره‌سازی` `رایگان` `۵ دقیقه`

برای اجرای هوش مصنوعی اشتراکی (Claude/ChatGPT) روی GitHub Actions، پایگاه دانش و بایگانی داده‌ها در GitHub.

**پیش‌نیازها:** حساب GitHub (رایگان)

1. یک مخزن خصوصی (Private) بسازید، مثلاً seolity-runner. تیک «Add a README» را بزنید تا مخزن خالی نباشد. [ساخت مخزن جدید](https://github.com/new)
2. یک توکن Fine-grained بسازید: Resource owner = حساب خودتان، Repository access = Only select repositories و مخزن بالا را انتخاب کنید. [ساخت توکن Fine-grained (لینک مستقیم)](https://github.com/settings/personal-access-tokens/new)
3. در Repository permissions این‌ها را Read and write کنید: Contents، Actions، Secrets، Workflows. (Metadata خودکار Read می‌شود.) تاریخ انقضا را مثلاً ۹۰ روز یا بیشتر بگذارید.
4. راه ساده‌تر (توکن کلاسیک با دسترسی گسترده‌تر): این لینک دسترسی‌های repo و workflow را از پیش انتخاب می‌کند. [توکن کلاسیک repo + workflow](https://github.com/settings/tokens/new?scopes=repo,workflow&description=SEOlity)
5. «Generate token» را بزنید و توکن (github_pat_… یا ghp_…) را کپی کنید.

   ```
   github_pat_…
   ```
6. در SEOlity: تنظیمات ← GitHub ← «GitHub fine-grained token» ← Save. برای اشتراک AI، نام مخزن را در تب «هوش مصنوعی اشتراکی» (مثلاً username/seolity-runner) بنویسید.

**رفع مشکل**

- **403 Resource not accessible by personal access token** — یکی از دسترسی‌ها (معمولاً Secrets یا Workflows) داده نشده یا مخزن در فهرست توکن نیست. توکن را ویرایش کنید.
- **Git Repository is empty** — مخزن را با README بسازید یا یک فایل در آن commit کنید.
- **دقایق Actions تمام شده** — مخازن خصوصی سهمیه دقیقه ماهانه دارند. مصرف را در تنظیمات Billing گیت‌هاب ببینید.

**مستندات رسمی:** [مستندات توکن‌های دسترسی](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens) · [هزینه GitHub Actions](https://docs.github.com/en/billing/managing-billing-for-your-products/managing-billing-for-github-actions/about-billing-for-github-actions)

#### اشتراک Claude Pro / Max

`هوش مصنوعی اشتراکی` `بدون هزینه API` `۱۰ دقیقه`

از اشتراک Claude خودتان استفاده می‌کند (بدون خرید اعتبار API). درخواست‌ها روی GitHub Actions با Claude Code اجرا می‌شوند. ابتدا راهنمای «GitHub token» را انجام دهید.

**پیش‌نیازها:** اشتراک فعال Claude Pro یا Max؛ Node.js 18 یا جدیدتر روی کامپیوتر خودتان (فقط برای یک‌بار گرفتن توکن)

1. Node.js (نسخه LTS) را نصب کنید. [دانلود Node.js](https://nodejs.org/en/download)
2. Claude Code را نصب کنید (در ترمینال/PowerShell):

   ```
   npm install -g @anthropic-ai/claude-code
   ```
3. این دستور را اجرا کنید؛ مرورگر باز می‌شود و با حساب Claude وارد می‌شوید. در پایان یک توکن بلندمدت (sk-ant-oat…) چاپ می‌شود:

   ```
   claude setup-token
   ```
4. توکن را کامل کپی کنید و در SEOlity: تنظیمات ← «هوش مصنوعی اشتراکی» ← «Claude subscription token» بچسبانید و Save بزنید.
5. روی «Set up GitHub runner» بزنید (Workflow و Secrets خودکار در مخزن ساخته می‌شوند)، سپس در تب هوش مصنوعی ارائه‌دهنده را «Claude subscription» بگذارید و تست بزنید.

**رفع مشکل**

- **claude: command not found** — ترمینال را ببندید و باز کنید یا مسیر npm global را به PATH اضافه کنید.
- **Invalid API key / 401 در اجرای Actions** — توکن منقضی یا ناقص است؛ دوباره claude setup-token را اجرا و ذخیره کنید، سپس «Set up GitHub runner» را بزنید.
- **پاسخ‌ها چند دقیقه طول می‌کشد** — طبیعی است (راه‌اندازی Actions). اگر سایت عمومی است گزینه «Send results directly to this site» را روشن کنید.

**مستندات رسمی:** [راه‌اندازی Claude Code](https://docs.claude.com/en/docs/claude-code/setup) · [Claude Code GitHub Action](https://github.com/anthropics/claude-code-action)

#### اشتراک ChatGPT Plus / Pro (Codex)

`هوش مصنوعی اشتراکی` `بدون هزینه API` `۱۰ دقیقه`

از اشتراک ChatGPT شما با Codex CLI روی GitHub Actions استفاده می‌کند. ابتدا راهنمای «GitHub token» را انجام دهید.

**پیش‌نیازها:** اشتراک ChatGPT Plus، Pro، Team یا Business؛ Node.js روی کامپیوتر خودتان

1. Codex CLI را نصب کنید: [دانلود Node.js](https://nodejs.org/en/download)

   ```
   npm install -g @openai/codex
   ```
2. وارد شوید و گزینه «Sign in with ChatGPT» را انتخاب کنید:

   ```
   codex login
   ```
3. محتوای کامل فایل auth.json را کپی کنید. مک/لینوکس: ~/.codex/auth.json — ویندوز: %USERPROFILE%\.codex\auth.json

   ```
   cat ~/.codex/auth.json
   ```
4. در SEOlity: تنظیمات ← «هوش مصنوعی اشتراکی» ← «ChatGPT login (auth.json)» کل JSON را بچسبانید و Save بزنید، سپس «Set up GitHub runner» و در تب هوش مصنوعی «ChatGPT subscription» را انتخاب و تست کنید.

**رفع مشکل**

- **not valid JSON** — کل فایل را از { تا } کپی کنید، نه فقط یک بخش.
- **خطای ورود بعد از چند هفته** — SEOlity توکن‌های تازه‌شده را خودکار ذخیره می‌کند؛ اگر باز خطا داد، codex login را دوباره اجرا و فایل را دوباره ذخیره کنید.

**مستندات رسمی:** [مخزن Codex CLI](https://github.com/openai/codex) · [مستندات Codex](https://developers.openai.com/codex)

### گوگل (سرچ کنسول و سرعت)

#### Google Search Console

`بسیار مهم` `رایگان` `۱۵ دقیقه`

قلب هوش SEOlity: کلمات کلیدی واقعی، کلیک، نمایش، جایگاه، کنیبالیزیشن و کلمات کلیدی کانونی از همین داده انتخاب می‌شوند. دسترسی فقط خواندنی (webmasters.readonly) است.

**پیش‌نیازها:** حساب گوگلی که در Search Console به سایت دسترسی دارد

1. مطمئن شوید سایت در Search Console ثبت و تأیید شده است (Domain یا URL prefix). [باز کردن Search Console](https://search.google.com/search-console)
2. در Google Cloud یک پروژه جدید بسازید (نام دلخواه مثلاً SEOlity). [ساخت پروژه (لینک مستقیم)](https://console.cloud.google.com/projectcreate)
3. Google Search Console API را برای همین پروژه فعال کنید (Enable). بالای صفحه مطمئن شوید پروژه درست انتخاب شده است. [فعال‌سازی Search Console API](https://console.cloud.google.com/apis/library/searchconsole.googleapis.com)
4. صفحه رضایت OAuth را بسازید: Google Auth Platform ← Branding ← Get started. نام برنامه و ایمیل پشتیبانی را وارد کنید، Audience را External بگذارید، ایمیل تماس را بدهید و Create بزنید. [Branding (صفحه رضایت)](https://console.cloud.google.com/auth/branding)
5. مهم: در Audience روی «Publish app» بزنید تا وضعیت In production شود. در حالت Testing، اتصال هر ۷ روز قطع می‌شود. (در حالت Testing باید ایمیل خود را در Test users اضافه کنید.) [Audience](https://console.cloud.google.com/auth/audience)
6. یک OAuth client بسازید: Clients ← Create client ← Application type: Web application. [ساخت OAuth client (لینک مستقیم)](https://console.cloud.google.com/auth/clients/create) · [یا از صفحه Credentials: Create credentials ← OAuth client ID](https://console.cloud.google.com/apis/credentials)
7. در «Authorized redirect URIs» دقیقاً آدرس زیر را اضافه کنید (همان که در صفحه سرچ کنسول SEOlity نمایش داده می‌شود):

   ```
   https://YOUR-SITE/wp-admin/admin-post.php
   ```
8. Create را بزنید و Client ID و Client secret را کپی کنید (Client secret با GOCSPX- شروع می‌شود).

   ```
   xxxxxxxx.apps.googleusercontent.com  /  GOCSPX-…
   ```
9. در SEOlity به صفحه «سرچ کنسول» بروید، Client ID و Secret را ذخیره کنید، «اتصال حساب گوگل» را بزنید، حساب را انتخاب و اجازه دهید، سپس Property سایت را انتخاب کنید. داده‌ها در پس‌زمینه همگام می‌شوند.

**رفع مشکل**

- **Error 400: redirect_uri_mismatch** — آدرس Redirect در Google Cloud دقیقاً با آدرس SEOlity یکی نیست (http/https، www، اسلش آخر). آن را از همین صفحه کپی کنید. تغییرات تا چند دقیقه طول می‌کشد.
- **Google hasn’t verified this app** — برای برنامه شخصی خودتان طبیعی است: Advanced ← Go to … (unsafe) را بزنید. برنامه فقط به داده‌های شما با دسترسی خواندنی وصل می‌شود.
- **Error 403: access_denied** — برنامه در حالت Testing است و ایمیل شما Test user نیست؛ آن را اضافه کنید یا Publish app بزنید.
- **هیچ Property نمایش داده نمی‌شود** — حساب گوگلی که وصل کردید به سایت در Search Console دسترسی ندارد. در Search Console ← Settings ← Users and permissions آن را اضافه کنید.
- **اتصال بعد از یک هفته قطع شد** — برنامه در حالت Testing مانده است. Publish app بزنید و دوباره وصل شوید.
- **داده‌ها امروز را نشان نمی‌دهند** — داده‌های Search Console حدود ۲ تا ۳ روز تأخیر دارند.

**مستندات رسمی:** [راهنمای Search Console API](https://developers.google.com/webmaster-tools/v1/how-tos/authorizing) · [تنظیم صفحه رضایت OAuth](https://developers.google.com/workspace/guides/configure-oauth-consent) · [افزودن سایت به Search Console](https://support.google.com/webmasters/answer/34592)

#### GitHub token

`Needed for subscriptions & storage` `Free` `5 min`

Runs subscription AI (Claude/ChatGPT) on GitHub Actions, and powers the knowledge base and data archive on GitHub.

**You need:** A GitHub account (free)

1. Create a PRIVATE repository, e.g. seolity-runner. Tick “Add a README” so it is not empty. [Create a repository](https://github.com/new)
2. Create a fine-grained token: Resource owner = you, Repository access = Only select repositories → choose the repository above. [New fine-grained token (direct link)](https://github.com/settings/personal-access-tokens/new)
3. Under Repository permissions set Read and write for: Contents, Actions, Secrets, Workflows (Metadata becomes Read automatically). Pick an expiry, e.g. 90 days or more.
4. Simpler alternative (classic token, broader access): this link preselects the repo and workflow scopes. [Classic token with repo + workflow](https://github.com/settings/tokens/new?scopes=repo,workflow&description=SEOlity)

   ```
   github_pat_…
   ```

**Troubleshooting**

- **403 Resource not accessible by personal access token** — A permission (usually Secrets or Workflows) is missing or the repo is not selected. Edit the token.
- **“Git Repository is empty”** — Create the repo with a README or commit any file.
- **Actions minutes used up** — Private repos have a monthly minutes quota. Check usage in GitHub Billing settings.

**Official docs:** [Personal access tokens docs](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens) · [GitHub Actions billing](https://docs.github.com/en/billing/managing-billing-for-your-products/managing-billing-for-github-actions/about-billing-for-github-actions)

### Google (Search Console & speed)

#### Google Search Console

`Most important` `Free` `15 min`

The heart of SEOlity: real queries, clicks, impressions, positions, cannibalization and focus-keyword picks all come from this. Access is read-only (webmasters.readonly).

**You need:** A Google account with access to the site in Search Console

1. Make sure the site is added and verified in Search Console (Domain or URL prefix). [Open Search Console](https://search.google.com/search-console)
2. Create a new Google Cloud project (any name, e.g. SEOlity). [Create project (direct link)](https://console.cloud.google.com/projectcreate)
3. Enable the Google Search Console API for this project (check the project picker at the top). [Enable Search Console API](https://console.cloud.google.com/apis/library/searchconsole.googleapis.com)
4. Configure the OAuth consent screen: Google Auth Platform → Branding → Get started. Enter app name and support email, Audience = External, contact email, then Create. [Branding (consent screen)](https://console.cloud.google.com/auth/branding)
5. Important: in Audience click “Publish app” (In production). In Testing mode the connection expires every 7 days. (In Testing you must add your email under Test users.) [Audience](https://console.cloud.google.com/auth/audience)
6. Create an OAuth client: Clients → Create client → Application type: Web application. [Create OAuth client (direct link)](https://console.cloud.google.com/auth/clients/create) · [Or via Credentials: Create credentials → OAuth client ID](https://console.cloud.google.com/apis/credentials)
7. Under “Authorized redirect URIs” add exactly this address (also shown on SEOlity’s Search Console page):

   ```
   https://YOUR-SITE/wp-admin/admin-post.php
   ```
8. Click Create and copy the Client ID and Client secret (the secret starts with GOCSPX-).

   ```
   xxxxxxxx.apps.googleusercontent.com  /  GOCSPX-…
   ```
9. In SEOlity open “Search Console”, save the Client ID and secret, click “Connect Google account”, choose the account and allow, then pick the site property. Data syncs in the background.

**Troubleshooting**

- **Error 400: redirect_uri_mismatch** — The redirect URI in Google Cloud does not exactly match SEOlity’s (http/https, www, trailing slash). Copy it from this page. Changes can take a few minutes.
- **“Google hasn’t verified this app”** — Normal for your own app: click Advanced → Go to … (unsafe). It only reads your own data.
- **Error 403: access_denied** — The app is in Testing and your email is not a test user; add it or click Publish app.
- **No properties are listed** — The connected Google account has no access in Search Console. Add it under Settings → Users and permissions.
- **Disconnected after a week** — The app is still in Testing. Publish it and reconnect.
- **No data for today** — Search Console data lags about 2–3 days.

**Official docs:** [Search Console API guide](https://developers.google.com/webmaster-tools/v1/how-tos/authorizing) · [Configure OAuth consent](https://developers.google.com/workspace/guides/configure-oauth-consent) · [Add a property](https://support.google.com/webmasters/answer/34592)
